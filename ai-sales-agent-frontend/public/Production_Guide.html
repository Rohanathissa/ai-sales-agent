2. Meta Permanent Access Token (Token Expire වීම වැළැක්වීම)

Developer Portal එකෙන් දෙන Temporary Token එක පැය 24 කින් Expire වන නිසා (Code 190 OAuthException), කවදාවත් expire නොවන System User Token එකක් මෙසේ ලබාගන්න:

  • Step 1 (Login): Go to Meta Business Suite ↪ business.facebook.com වෙත Login වන්න.
  • Step 2 (System Users): Settings ➔ Users ➔ System Users ↪ සැකසුම් මෙනුවෙන් System Users වෙත පිවිසෙන්න.
  • Step 3 (Create User): Add Admin System User ↪ නව Admin System User කෙනෙකු සාදන්න (උදා: GemConnect-Bot).
  • Step 4 (Assign Assets): Full Control on WABA & App ↪ WhatsApp Business Account සහ App එක තෝරා Full Control අවසර දෙන්න.
  • Step 5 (Generate Token): Expiration = 'Never' ↪ Expiration කාලය 'Never' (කවදාවත් Expire නොවන ලෙස) තෝරන්න.
  • Step 6 (Scopes): Check whatsapp_business_messaging & whatsapp_business_management.
  • Step 7 (Result): මෙම Token එක කවදාවත් expire නොවේ.
